# Security Policy

Security fixes are provided for the latest released version of each package in this repository. Older releases are unsupported after a newer version ships.

| Package           | Supported                |
| ----------------- | ------------------------ |
| `@zemd/color-mcp` | Latest published release |

Report vulnerabilities through [GitHub Private Vulnerability Reporting](https://github.com/zemd/ai/security/advisories/new) or email `oss@zemd.dev` with the subject `SECURITY: <package name>`.

Do not report a vulnerability in a public issue. Include the affected version, runtime, impact, and minimal reproduction. Scanner output without a demonstrated impact is not a reproduction; it is a weather report.
